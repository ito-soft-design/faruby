# mruby との違い

faRuby は mruby のバイトコードを実行しますが、**言語としては部分集合**です。
ここは「Ruby として書いたつもりのものが faRuby でどうなるか」の一覧です。

PLC のハードウェアから来る違い (実数の 0 除算、デバイスの幅、ビットデバイスの
真偽) は [Ruby と PLC の違い](ruby_and_plc.md) にあります。

## 1. 動くが意味が違う

**一番気をつけるところです。** 止まらないので気づきません。

| 書き方 | Ruby | faRuby |
|-------|------|--------|
| `:foo < 1` / `[9] < 100` / `nil < 1` | `NoMethodError` | **黙って比べる** (下記) |
| `2147483647 + 1` | `2147483648` | **`-2147483648`** (32ビットで回り込む) |
| `1.0 / 0` を演算に使う | `Infinity` のまま計算 | **PLC が軽度エラー** |
| `1.0e30 * 1.0e30` | `Infinity` | `Infinity`。以降の比較が**嘘を返す** |
| `a[12] = 1` (容量超え) | 配列が伸びる | **エラー 10 で停止** |
| `a[-5] = 1` (行き過ぎ) | `IndexError` | エラー 2 で停止 |
| ループの中で配列や文字列を作り続ける | GC が回収 | **16 個でエラー 10** |
| ループの中の `s[i]` | GC が回収 | **1 文字ごとに 1 スロット。16 回で止まる** |
| `h.each { \|k\| }` | `k` に `[鍵, 値]` の配列 | **鍵だけ** (下記) |
| `0.1 + 0.2` | 倍精度 | **単精度**。桁が少ない |

### 大小比較は型を見ません

`<` `<=` `>` `>=` は**タグが実数かどうかだけ**を見て、それ以外は値をそのまま
整数として比べます。値というのは、シンボルなら通し番号、配列ならスロット番号、
`nil` なら 0 です。実測した結果です。

```ruby
:foo < 100    # → true  (:foo の通し番号 1 と 100 を比べている)
[9] < 100     # → true  (スロット番号 0 と 100 を比べている)
nil < 1       # → true  (0 と 1 を比べている)
true < 1      # → false (1 と 1 を比べている)
```

**等値 (`==` / `!=`) は型を見ます。** `:foo == 1` は偽です。型の違うもの同士を
`==` で比べるのは Ruby でも正当な書き方なので、こちらは合わせました。

大小比較を止めるようにしないのは、`while i < 10` のような**最も多く通る経路**に
型検査を足すことになるためです。数値でないものを `<` で比べるのは Ruby なら
エラーになる書き間違いで、意図して書く形ではないと判断しました。

### h.each はブロックの引数の数で渡すものが変わりません

Ruby は `h.each { |k| }` の `k` に `[鍵, 値]` の 2 要素配列を渡します。
faRuby は鍵だけを渡します。**配列を毎回作るとプールを食い潰す**ためです。

```ruby
h = { 1 => 10 }
h.each { |k, v| }   # k=1, v=10  同じ
h.each { |k| }      # Ruby は k=[1, 10]、faRuby は k=1
```

2 つ受ける書き方は同じなので、普通に書いている限り差は出ません。

## 2. 使うと止まる

未実装です。実行時に `ERROR` を立てて停止します。コードの意味は
[ロードマップのエラーコード](roadmap.md#エラーコード)にあります。

| 書き方 | 備考 |
|-------|------|
| `s * 2` | 未実装。エラー 4 (`OP_MUL` は数値だけ) |
| `s[1, 2]` / `s[1..2]` | 未実装。添字は 1 文字ぶんだけ |
| `s.sub` / `s.upcase` / `format` | 未実装。エラー 3 |
| `class Foo` | 未実装。`OP_CLASS` / `OP_EXEC` が要る |
| `begin` / `rescue` | 例外機構を持たない |
| `@x` / `@@x` | インスタンス変数・クラス変数は未実装 |
| `CONST` を読む | `FARUBY_` で始まる設定への代入だけ効く。読むと未知の命令で止まる |
| `def f(a, b = 1)` | 省略可能引数。エラー 6 |
| `def f(*a)` / `def f(k:)` | 可変長・キーワード引数。エラー 6 |
| `yield` / `def f(&blk)` | ブロックを受け取る仕組みが無い |
| `loop do ... end` | `OP_SSENDB` で別命令。`while true` で代用 |
| `obj.foo` (自分で定義したメソッド) | **エラー 3。** レシーバを書かない `foo` なら動く |
| `a.pop` など未対応のメソッド | エラー 3。使えるものは [README の一覧](../README.md#組み込みメソッド) |
| `"ab".push("c")` | Ruby にも無い。faRuby もエラー 4 |

**未実装の命令に当たると `ERROR` にオペコード番号が入ります。** 1-10 の
エラーコードと重ならないので区別できます。番号は
[対応オペコード一覧](opcodes.md) で引けます。

## 3. 同じにしてあるもの

差があると思われがちですが、合わせてあります。

| 書き方 | 動作 |
|-------|------|
| `if 0` | **真**。偽は `nil` と `false` だけ |
| `-7 / 2` | `-4` (切り下げ)。PLC の除算は 0 方向へ切り捨てるので補正している |
| `-7 % 3` | `2` (符号は除数に合う) |
| `2.5.round` / `-2.5.round` | `3` / `-3` (0 から遠い方へ) |
| `-1.5.floor` | `-2` (−∞ 方向へ) |
| `1 == 1.0` | **真**。数値は型が違っても値で比べる |
| `nil == false` | **偽**。数値以外は型も一致すること |
| `a[-1]` | 最後の要素 |
| `a[5]` (要素数超え) | `nil` |
| `5.upto(3) { }` | 1 回も回らない |
| メソッドの戻り値 | 最後の式。途中の `return` も動く |
| ブロックの引数の数 | 足りなければ `nil`、余れば捨てる |

## 4. 数の扱い

| | Ruby | faRuby |
|---|------|--------|
| 整数 | 多倍長 | **32ビット符号付き**。桁あふれは検出せず回り込む |
| 実数 | 倍精度 | **単精度** (IEEE754 32ビット) |
| 整数と実数の混在 | 実数になる | 同じ |

多倍長を持ち込まないのは、PLC のデバイスが固定幅である以上、意味が薄いためです。

## 5. これから変わるかもしれないもの

| 項目 | 現状 |
|------|------|
| 配列と文字列の回収 | 今は回収しない。必要になればマークスイープを足せる。[ヒープの計画](heap.md) |
| `Symbol#to_s` | シンボルの値は番号で、名前は VM 側に無い。文字列があっても戻せない |
| 文字コードをまたぐ比較 | 1 プログラム 1 ソースなので、リテラルどうしは必ず同じ文字コード。[文字列の計画](string.md) |
