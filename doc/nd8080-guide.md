# ND8080 実機での実行ガイド

faRuby の i8080 バックエンドを中日電工 ND8080 ボードで動かす手順。

## 前提条件

| 項目 | 内容 |
|------|------|
| ND8080 ボード | USB で Mac/PC に接続済み |
| DS1 設定 | #1=ON (ND80Z モニタ, FFxx ワークエリア) |
| hidapi | macOS: `brew install hidapi` |
| mrbc | mruby コンパイラ (PATH に入っていること) |
| asm80 | i8080 アセンブラ (PATH に入っていること) |
| r8080 | i8080 エミュレータ (環境変数 `R8080_PATH` またはリポジトリ隣) |

## クイックスタート

```bash
# 1. VM をビルド (定数生成 + アセンブル)
rake i8080:build

# 2. ND8080 をリモートモードにする
#    ボード上で [＊(I/O)] → [8] を押す

# 3. Ruby プログラムをコンパイル → ND8080 に書き込み
rake i8080:upload SRC=test/ruby_programs/test_01_literal.rb

# 4. 実行
rake i8080:nd8080_run
```

プログラム終了後、自動的にリモートモードに復帰するため、
手動で I/O\*+8 を押し直す必要はない。

## Rake タスク一覧 (i8080 名前空間)

| タスク | 説明 |
|--------|------|
| `i8080:build` | `vm_constants.a80` 再生成 + アセンブル |
| `i8080:run SRC=...` | Ruby ソースをコンパイル → r8080 エミュレータで実行 |
| `i8080:hex SRC=...` | 結合 Intel HEX ファイルを生成 |
| `i8080:upload SRC=...` | コンパイル → ND8080 に USB で書き込み (照合付き) |
| `i8080:nd8080_run` | ND8080 上で 0x8400 から実行 |

## nd8080.rb (低レベルツール)

`tools/nd8080.rb` は ND8080 と USB-HID で直接通信する CLI ツール。

```bash
ruby tools/nd8080.rb info                    # 接続確認
ruby tools/nd8080.rb dump 8000 800F          # メモリダンプ
ruby tools/nd8080.rb poke 8000 3E 50 FF      # バイト書き込み
ruby tools/nd8080.rb load prog.btk --verify  # BTK ファイル書き込み
ruby tools/nd8080.rb run 8400                # 実行
```

## メモリマップ

```
0x8000-0x80FF  VM 状態          256B
0x8100-0x81FF  レジスタファイル  256B (32 スロット × 4B + 128B 型タグ)
0x8200-0x82FF  IREP テーブル     256B
0x8400-0x8FFF  VM コード         3KB  (org 8400h)
0x9000-0x9FFF  バイトコード      4KB
0xA000-0xA7FF  定数プール        2KB
0xF000-0xFDFF  CPU スタック      3.5KB
0xFFB8-0xFFF7  ND80Z モニタワーク (触れないこと)
0xFFF8-0xFFFF  7 セグ表示 (DIG)  8B
```

**注意:** 0x83C7-0x83F7 は ND80Z の割り込みベクタが使用するため、
データを配置してはならない。

## VM 停止後のリモート復帰

VM が停止すると `vm_halt` が N80MON2D ジャンプテーブルの
REMOTE エントリ (`$0821`) にジャンプする。
これは `REMOTEMK` を設定して RST5/RST6 ハンドラを差し替えるため、
I/O\*+8 を手動で押したのと同じ状態になる。

エミュレータ (r8080) では ROM 領域 (< 0x8000) へのジャンプを
検出して停止するため、実機との動作の違いは吸収される。

## 7 セグメント表示

ND8080 のセグメントパターンは標準 TK-80 と 2 箇所異なる。

| 数字 | 標準  | ND8080 |
|------|-------|--------|
| 0    | 0x3F  | 0x5C   |
| 7    | 0x07  | 0x27   |

VM の `seg_table` と `display_hex16` はこのパターンに合わせてある。

## トラブルシューティング

**「ND8080 が見つかりません」**
- USB ケーブルが接続されているか確認
- `brew install hidapi` が完了しているか確認

**「ND8080 から応答がありません」**
- ボード上で [＊(I/O)] → [8] を押してリモートモードを有効化する
- リセットボタンを押してから再度 [＊(I/O)] → [8]

**照合 NG**
- 書き込み先アドレスが割り込みベクタ領域 (0x83C7-0x83F7) と
  重なっていないか確認
